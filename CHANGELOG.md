# Changelog

All notable changes to **JobRadar** are documented here.

---

## [1.0.0] — 2026-10-18

### ✨ Added
- CLI that takes a role and location and prints a ranked table of matching listings
- BeautifulSoup parser for job cards, with a local fixture for offline runs
- Weighted fit score from a configurable skills profile, with word-boundary matching
- pandas de-duplication that keeps the best-scoring copy of each listing
- CSV export of every ranked listing, dated by run
- Live mode with a `robots.txt` check and rate limiting
- Next.js project page
